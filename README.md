# Альфинатор — интерактивная демонстрация

Автономный сценарный показ портала и помощника в 1С.
Действие зрителя — отправка подготовленных сообщений. Все данные вымышлены.
Запросы к API и реальным базам не выполняются.

## GitHub Pages

1. Создать отдельный публичный репозиторий `alfinator-demo`.
2. Загрузить содержимое этой папки в корень ветки `main`.
3. В Settings → Pages выбрать Deploy from a branch, main, / (root).
4. Дождаться публикации и открыть ссылку, показанную GitHub.

В папке только статическая демка и учебные Word/Excel. Для показа не нужны ключи или сервер.
